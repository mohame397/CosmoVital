CosmoVital — النسخة المحلية دون حساب أو قاعدة بيانات

التشغيل الأسهل دون إنترنت:
1. نزّل ملف CosmoVital-Offline.html على الكمبيوتر.
2. احتفظ به في مجلد ثابت، وافتحه بالدبل كليك في Chrome أو Edge.
3. كل ملفات الشكل والخطوط والصور وبيانات البحث مضمنة داخله.
4. سجل القياسات الحقيقية بوقتها. لا يلزم تسجيل دخول أو Supabase.

الحفظ:
- البيانات تحفظ محليًا في نفس المتصفح، وليست نسخة سحابية.
- أي شخص يستخدم نفس المتصفح/الملف قد يرى السجل نفسه؛ لا توجد حسابات منفصلة.
- حفظ صفحات file:// يختلف حسب المتصفح. احتفظ بالملف في نفس المكان، واستخدم نفس المتصفح، وتأكد من بقاء قراءة تجريبية بعد غلق الصفحة وفتحها.
- صدّر Full workspace backup دوريًا واحفظ نسخة JSON خارج المتصفح. ملفات النسخ غير مشفرة.
- مسح بيانات المتصفح أو استخدام وضع التصفح الخاص أو نقل الملف قد يفقد أو يفصل التخزين. لا تحذف النسخة الاحتياطية قبل التأكد من الاسترجاع.
- النسخة المحلية لا تسحب البيانات القديمة من Supabase تلقائيًا. صدّرها من الموقع القديم أولًا ثم استوردها باختيارك.

للنسخة المرفوعة على موقع:
- ارفع محتويات مجلد Web كلها معًا، بحيث يكون index.html في جذر النشر.
- زيارة الموقع لأول مرة تحتاج الإنترنت لتحميل ملفات الموقع وتخزينها. بعد نجاح التخزين يمكن فتح نفس الرابط دون اتصال في متصفح يدعم Service Worker.
- ملف CosmoVital-Offline.html مستقل، ويمكن فتحه أول مرة دون نت بعد تنزيله.

لو منع متصفحك الحفظ عند فتح الملف مباشرة:
- استخدم النسخة متعددة الملفات مع خادم محلي. بعد تثبيت Python 3، من داخل مجلد المصدر شغّل:
  python scripts/start-local.py
- أو من مجلد Web الذي يحتوي index.html شغّل:
  python -m http.server 8080 --bind 127.0.0.1
- افتح http://127.0.0.1:8080 واترك نافذة الخادم مفتوحة. الخادم المحلي لا يحتاج الإنترنت ولا يرسل البيانات إلى خارج جهازك.

روابط المراجع العلمية الأصلية تحتاج اتصالًا لفتح مواقعها. نصوص الإرشادات وبيانات البحث المرفقة متاحة داخل الملف.
التطبيق يسجل وينظم القياسات، وليس تشخيصًا أو اعتمادًا طبيًا لرحلات الفضاء.

الأجزاء الجديدة التي تميز النسخة:
- Mission evidence trail / مسار القياس والمتابعة: القياس ومصدره، جودة السياق، سبب التنبيه، الإجابات المحفوظة، وملخص للمراجع.
- Guided follow-up / متابعة سؤال بسؤال: يظهر تلقائيًا بعد حفظ قراءة تستدعي الانتباه حسب المراجع العامة. العلامات الشديدة تعرض طلب المساعدة فورًا.
- Spaceflight context / سياق الرحلة الفضائية: مخاطر NASA الخمسة وحدود ما تقيسه المؤشرات الفعلية، والمراجع الخمسة المرسلة من NASA وCSA.

حفظ الجهاز المقصود اسمه LocalStorage، وليس SSH keys أو تسجيل حساب. السجل مرتبط بالمتصفح ومكان الملف، وليس هوية جهاز موثقة.
